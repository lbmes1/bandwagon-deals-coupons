2025 年 11 月是个分界线。当月双十一，搬瓦工给出了 11% 的全场循环码 ILOVEBANDWAGON，这是近年力度最大的一次促销——然后活动结束时，常规优惠码体系一起被收走了。

## 优惠码怎么用：结账页这样填

假如下次真出了新码，操作流程是这样的：

1. 注册并登录账号，选好套餐加入购物车；
2. 进入结账页，在 **Promotional Code** 输入框填入优惠码，点击旁边的 Validate 按钮；
3. 确认订单金额确实变化了，再选择支付方式（支持支付宝、PayPal 等）完成付款。

三个常见的坑值得提前知道。第一，如果填码后提示无效，大概率是码过期了，而不是你操作错了——空窗期里这是常态。第二，有个别限量套餐（比如 BIGGERBOX 系列）会把 Promotional Code 这一栏当邀请码用，没有邀请码根本无法下单，社区里的常见做法是注册后发工单向客服索要。第三，付款前返回购物车还能补填优惠码，一旦付完款再想补，就只能开工单和客服商量了，能不能补不保证，所以下单前多看一眼金额。

## 常见问题

**现在网上流传的搬瓦工优惠码还能试吗？**
能试，但基本都会提示无效。2025 年 11 月之后的常规码已全部取消，2026 年内只出现过存活两天的 NODESEEK2026。试错成本为零，不过别因为试了没效果就怀疑自己操作错了。

**循环优惠码对老用户续费有用吗？**
